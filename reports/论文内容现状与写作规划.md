## 2. 论文要抓住的核心问题

建议将论文核心问题明确为：

> **LLM 在复杂情感语义任务中，究竟是在真正理解上下文，还是主要依赖表层情感词和模板线索？这种能力在 sarcasm、metaphor 和 adversarial 场景下会如何退化，而 prompt-aware 设计是否能够系统性缓解这种退化？**

这个问题与当前项目高度匹配，因为它能自然连接：

- 数据集构造
- baseline 设计
- 真实模型比较
- 鲁棒性分析
- 错误案例分析

换句话说，你的论文不是“跑了几个模型”，而是：

> **系统检验 LLM 是否真的理解复杂情感语义。**

## 3. 你已经发现了什么值得研究的问题

### 3.1 复杂情感理解不是普通分类

normal 与 sarcasm / metaphor / adversarial 的差异表明：

- 模型在显式情感上通常更稳
- 一旦进入反讽、隐喻、对抗扰动，性能明显下降
- 问题不只是“分类是否正确”，而是“模型是否真的利用了上下文”

这意味着论文主题应被定义为：**复杂情感语义理解能力评测**。

### 3.2 表层线索会误导模型

Literal-Keyword 与 Prompt-Aware 的差异说明：

- 仅依赖关键词会在 sarcasm 和 adversarial 场景中失效
- 引号、emoji、语气词、反转表达、混合语言都会干扰判断
- 模型可能“看到了情感词”，却没有真正理解情感方向

因此，一个很强的研究切入点是：

> **LLM 是否过度依赖 surface cues（表层线索）？**

### 3.3 Prompt 本身就是实验变量

你在 `gemini-2.5-pro` 的实验中已经观察到：

- baseline 与 CoT 不一定谁都更好
- prompt 变化会显著影响结果

这说明论文不只是在讨论模型本身，也在讨论：

> **评测提示设计是否会显著改变复杂情感任务上的表现？**

### 3.4 鲁棒性比总准确率更能说明问题

由于负类占比偏高，仅看 Accuracy 容易误导。相比之下：

- adversarial accuracy
- robustness score

更能说明模型是否真的稳定。

所以论文重点应从“谁分数更高”转向：

> **谁更稳、谁更会理解复杂语境。**

## 4. 论文目录建议

### 第 1 章：研究背景与问题定义

建议写清楚：

- 为什么普通情感分类不够
- 为什么复杂情感语义更能检验 LLM
- 你的论文到底想回答什么问题

本章建议中心句：

> 现有 LLM 在显式情感上表现不错，但在复杂情感语义下是否真的“理解”，仍然缺乏系统检验。

### 第 2 章：相关工作

建议只保留与论文主问题强相关的内容：

- 情感分类
- 反讽理解
- 隐喻理解
- LLM benchmark / robustness / prompt sensitivity

### 第 3 章：数据集与任务设计

本章是论文方法核心，应说明：

- 四类样本如何定义
- 标签体系如何设计
- 为什么这四类能构成复杂情感语义 benchmark
- 数据规模与分布情况

本章回答：

> **我构造了什么问题？**

### 第 4 章：实验设置与评测指标

建议说明：

- Level 0 / 1 / 2 的分级标准
- prompt 设计思路
- baseline 设定
- 真实模型接入方式
- 评测指标定义

本章回答：

> **我如何保证实验可复现、可比较？**

### 第 5 章：总体结果

建议先放主结果表，再放图：

- 总体对比表
- 混淆矩阵
- 类型准确率图
- 鲁棒性图
- Prompt 对比图

本章回答：

> **哪些方法/模型整体更好？**

### 第 6 章：系统化分析

本章不要只是堆数字，而要按问题驱动展开：

#### 6.1 表层线索依赖
分析为什么词表法会误导模型。

#### 6.2 反讽与隐喻脆弱性
分析为什么 sarcasm / metaphor 是难点。

#### 6.3 对抗扰动影响
分析 emoji、引号、混合语言、语义反转对模型的影响。

#### 6.4 Prompt 是否改善理解
分析 prompt-aware 是否真能提升复杂情感理解。

本章回答：

> **模型为什么错？错在哪里？为什么会错？**

### 第 7 章：讨论

本章建议总结成研究发现：

- LLM 的复杂情感理解不是“会不会分类”，而是“能不能正确理解语境”
- prompt 设计会显著影响结果
- robustness 比单一 accuracy 更有解释力
- benchmark 设计本身会影响你观察到的能力边界

### 第 8 章：结论与展望

建议写：

- 已经验证了什么
- 还可以扩展什么
- Level 3、更多模型、更多对抗样本、统计显著性检验等未来方向

## 6. 论文写作脉络建议

整篇论文最合适的逻辑脉络是：

1. **我为什么要研究复杂情感理解**
2. **我构造了什么 benchmark**
3. **我如何设计评测与 prompt**
4. **模型在总体上表现如何**
5. **它们在哪些类型上退化最严重**
6. **这种退化是否与表层线索、prompt、鲁棒性相关**
7. **我最终得出了什么研究结论**

这个结构的优点是：

- 不是简单报分数
- 能突出“研究问题”
- 能解释“为什么值得研究”
- 能自然导出后续展望
